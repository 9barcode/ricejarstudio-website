# 쌀독탈출 · Rice Jar Studio

Official studio website, hosted on Cloudflare Pages.

## Deploy
Cloudflare Dashboard → Workers & Pages → Create → Pages → Connect to Git → `9barcode/ricejarstudio-website` → Production branch `main` → Framework preset `None` → Build command empty → Build output directory `/`.

## Before public verification
Replace business contact placeholders on the home page and review the privacy policy and terms to match actual data practices. Never publish made-up business registration details.
